# Jordan Ranch & Tamarron

Private resident marketplace and local business network for verified Jordan Ranch and Tamarron residents.

## Core navigation

- Home
- Marketplace
- Local Business
- Deals
- Profile

## Product rules

- Residents must verify residency in Jordan Ranch or Tamarron.
- Public profiles show first name + last initial, profile photo, community, profession, optional business name, verified status, and member-since date.
- Residential addresses are used only for verification and are never shown publicly.
- Saved content is private to the account owner.
- No likes or comments on Home content.
- Marketplace, Local Business ads, and Deals may show view counts and relevant performance metrics.
- Businesses can advertise with image ads, video ads, deals, featured placements, and coming-soon/grand-opening campaigns.

## Stack

Next.js + TypeScript + Tailwind CSS + Supabase + Vercel.
